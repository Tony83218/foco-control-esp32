=== ESQUEMA DE CONEXIÓN PARA ESP32-WROOM-32 ===

CIRCUITO PRINCIPAL:

ESP32-WROOM-32:
- GPIO 5 → LED (a través de resistencia 220Ω)
- GPIO 4 → Sensor PIR (pin OUT)
- GND → Masa común
- 5V → Alimentación
- USB → Programación

Sensor PIR (HC-SR501):
- VCC → 5V
- GND → GND (masa común)
- OUT → GPIO 4 (lectura digital)

LED:
- Ánodo (+) → GPIO 5 (a través de resistencia 220Ω)
- Cátodo (-) → GND (masa común)

=== CONEXIONES DETALLADAS ===

=== CONEXIÓN DEL LED ===

LED:
    ┌──────────────────┐
    │  Resistencia 220Ω │
    │  ┌──────────────────┐
    │  │ GPIO 5 (ESP32) ──┤├──→ LED (+) ánodo
    │  └──────────────────┘
    │
    └──→ LED (-) cátodo ──→ GND

=== CONEXIÓN DEL SENSOR PIR (HC-SR501) ===

Sensor PIR:
    ┌──────────────┐
    │  HC-SR501    │
    │  ┌────────┐  │
    │  │ GND │ IN │ VCC │
    │  └────────┘  │
    │   │    │      │
    │   │    │      └──→ 5V (ESP32)
    │   │    └──────────→ GPIO 4 (ESP32)
    │   └───────────────→ GND (ESP32)

=== ALIMENTACIÓN ===

Fuente de 5V:
- Positivo (+) → ESP32 5V
- Positivo (+) → Sensor PIR VCC
- Negativo (-) → GND (masa común)

Tierra común (GND):
- ESP32 GND
- Sensor PIR GND
- LED (-) cátodo

=== CABLE USB ===

Para programar el ESP32:
- USB (PC) ↔ Micro USB (ESP32)
- TX/RX se configuran automáticamente
- Velocidad: 115200 baud

=== ESPECIFICACIONES TÉCNICAS ===

LED:
- Voltaje de operación: 3.3V - 5V
- Corriente máxima: 20mA
- Resistencia limitadora: 220Ω

Sensor PIR (HC-SR501):
- Voltaje de operación: 5V
- Corriente: 50-65mA
- Rango de detección: 5-20 metros
- Ángulo de detección: 110°
- Tiempo de activación: 2-3 segundos
- Tiempo de desactivación: 2-3 segundos

ESP32-WROOM-32:
- Voltaje de operación: 3.3V (GPIO)
- Corriente: hasta 80mA por GPIO
- Frecuencia WiFi: 2.4GHz
- WiFi Mode: AP (Access Point)

=== COMPONENTES NECESARIOS ===

- 1x ESP32-WROOM-32 DevKit
- 1x Sensor PIR HC-SR501
- 1x LED (RGB o blanco)
- 1x Resistencia 220Ω (para LED)
- 1x Cable USB Micro
- 4-6x Cables jumper (macho-hembra)
- 1x Fuente 5V 2A mínimo
- Tubo termoencogible (opcional, para aislar conexiones)

=== NOTAS IMPORTANTES ===

1. El sensor PIR necesita 30-60 segundos para calibrar al iniciar
2. La resistencia 220Ω limita la corriente del LED a ~15mA (seguro)
3. La tierra (GND) debe ser común entre todos los componentes
4. Evita conexiones sueltas; usa soldadura o connectors firmes
5. El sensor PIR tiene dos potenciómetros: sensibilidad y tiempo de delay
